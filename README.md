PHISHING URL DETECTOR
=====================

Project Description:
This project detects suspicious URLs using Python.
It analyzes URLs for common phishing indicators.

Features:
1. Suspicious keyword detection
2. IP address detection
3. @ symbol detection
4. Multiple hyphen detection
5. URL length analysis
6. HTTPS check
7. Risk score calculation
8. Risk level classification

Risk Levels:
0-1  : LOW RISK
2-4  : MEDIUM RISK
5+   : HIGH RISK

Technology Used:
- Kali Linux
- Python 3
- Regular Expressions

Main File:
detector.py

Purpose:
To demonstrate basic phishing URL detection
using URL-based security indicators.
